Paradigma Divide and Conquer

Prinsip Utama: Memecah masalah besar menjadi sub-masalah kecil yang serupa.
TAHAP 1

DIVIDE

Memecah masalah asli menjadi bagian-bagian kecil.

>>
TAHAP 2

CONQUER

Menyelesaikan tiap bagian secara independen.

>>
TAHAP 3

COMBINE

Menggabungkan solusi (Opsional pada Binary Search).

Karakteristik pada Pencarian: Digunakan untuk mengeleminasi elemen data yang tidak relevan sejak awal proses.
07

Algoritma Binary Search

[ ! ] Aturan Mutlak: Data harus dalam kondisi terurut (sorted).

> Cara Kerja:

1. Menentukan titik tengah (mid).
2. Membandingkan mid dengan target.
3. Mengeliminasi setengah bagian array yang tidak mungkin memuat target.
4. Pencarian dilanjutkan pada paruh yang tersisa secara berulang.

Kondisi Batas dan Variabel Pointer

> Variabel Penunjuk Utama:

low

Indeks batas bawah rentang aktif.

mid

Titik tengah rentang.

mid = ⌊(low + high) / 2⌋
high

Indeks batas atas rentang aktif.

Kondisi Berhenti: Pencarian berakhir jika target ditemukan atau low > high.
10

Tracing Pencarian (Iterasi 1 - 2)

ITERASI 1
  • low=0, high=9, mid=4.
  • Nilai Array[4]=35.
  • Evaluasi: 57 > 35. Target di paruh kanan.
  • low naik menjadi 5.
ITERASI 2
  • low=5, high=9, mid=7.
  • Nilai Array[7]=62.
  • Evaluasi: 57 < 62. Target di paruh kiri.
  • high turun menjadi 6.
11

Tracing Pencarian (Iterasi 3 - 4)

ITERASI 3
  • low=5, high=6, mid=5.
  • Nilai Array[5]=44.
  • Evaluasi: 57 > 44. Target di paruh kanan.
  • low naik menjadi 6.
ITERASI 4
  • low=6, high=6, mid=6.
  • Nilai Array[6]=57.
  • Evaluasi: 57 == 57.
  • > TARGET DITEMUKAN!

Linear Search vs. Binary Search

> Hasil Studi Kasus (n=10)

LINEAR SEARCH

7x

Pengecekan (sekuensial)

BINARY SEARCH

4x

Iterasi (logaritmik)

Analisis: Binary Search mampu mengunci target secara presisi dengan jumlah operasi yang jauh lebih sedikit melalui pembagian rentang secara konsisten.
13

Pembuktian Kompleksitas Waktu O(log n)

Penyusutan data per tahap:

n, n/2, n/4, ..., n/2k

Kondisi Terburuk (Worst-case) saat sisa data = 1:

n / 2k = 1  →  n = 2k

Aplikasi Logaritma Basis 2:

log2 n = log2 (2k)  →  k = log2 n
Kesimpulan: Kompleksitas waktu adalah O(log n)
14

Analisis Kompleksitas Ruang (Space Complexity)

  • Implementasi iteratif tidak menduplikasi array input ke memori baru.
  • Hanya memanipulasi variabel primitif integer (low, high, mid).
  • Alokasi memori bersifat statis/tetap tanpa terpengaruh lonjakan jumlah data n.
Kesimpulan: Kompleksitas ruang bersifat konstan atau O(1)

Kesimpulan Akhir

Binary Search adalah instrumen superior untuk data berskala masif dengan syarat data terurut.

Paradigma Divide and Conquer mereduksi kompleksitas waktu secara drastis dari linear O(n) menjadi logaritmik O(log n).

Efisiensi terbukti dari perbandingan 4 iterasi (Binary) vs 7 pengecekan (Linear) pada kasus nyata.

Penggunaan memori sangat hemat (konstan O(1)) karena hanya memanipulasi pointer indeks.

Optimalisasi algoritma jauh lebih krusial daripada sekadar meningkatkan kapasitas hardware.
